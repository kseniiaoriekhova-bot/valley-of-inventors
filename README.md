# Долина винахідників

Гра-спостереження: ти нічого не робиш, лише дивишся. Поселенці (NPC) і тварини живуть самі. Поселенці збирають, полюють, рибалять, навчають одне одного, допомагають голодним і **винаходять** — пристрої та нові матеріали, які мають працювати за спрощеними, але послідовними законами фізики й хімії.

## Запуск

Без збирання і без сервера:

- відкрий `index.html` у браузері, **або**
- відкрий `dist/valley-of-inventors.html` — та сама гра в одному файлі.

Після змін у коді перезбери одно-файлову версію: `python3 build.py`.

## Як це влаштовано

| Шар | Файл | Що робить |
|---|---|---|
| Закони природи | `js/data.js` | Властивості матеріалів, закони нагрівання, генератор сплавів і композитів, каталог реальних матеріалів, перевірка пристроїв |
| Світ | `js/world.js` | Карта, ресурси, тварини (кролі, олені, вовки, риба) |
| Поселенці | `js/sim.js` | Потреби, дії, знання, навчання, ідеї, експерименти, заохочення, народження |
| LLM-мозок | `js/llm.js` | Необов'язкове підключення відкритої моделі |
| Малювання | `js/render.js` | Canvas |
| Інтерфейс | `js/ui.js`, `index.html`, `css/style.css` | Хроніка, мешканці, відкриття, налаштування |

### Закони природи
- Кожен матеріал має твердість, міцність, гнучкість, міцність на розрив, густину, жаростійкість, температуру плавлення, водонепроникність, гостроту, прозорість, провідність і електродний потенціал.
- Температура залежить від палива (деревина 600°C, деревне вугілля 1100°C, кам'яне вугілля 1200°C), печі (+150°C, жар без повітря) і міхів (+300°C). **Стіни печі тріскаються**, якщо жар перевищує їхню жаростійкість: кам'яна піч не дасть більше 1200°C, тож для заліза потрібна керамічна або цегляна.
- Закони: піроліз деревини, спікання глини, цегла, кальцинація вапняку, гасіння вапна, вичинка шкіри, відновлення руд (свинець, олово, мідь, залізо), скло.
- Пристрій працює, лише якщо матеріал кожного «гнізда» має потрібні властивості (лезо — тверде й гостре, поплавок — легший за воду, гальванічний елемент — два **різні** метали з різницею потенціалів).

### Нові матеріали
Поселенці можуть сплавляти метали в довільних пропорціях (зокрема залізо з вуглецем) і змішувати основу (глину, вапно, смолу) з наповнювачем. Властивості рахуються з правил змішування: зміцнення, крихкість, зниження температури плавлення, армування волокнами.

- Якщо склад збігається з реальним матеріалом — **справжня назва** (бронза, дзвонова бронза, спекулум, п'ютер, припій, м'яка й вуглецева сталь, чавун, саман, вапняний розчин, цем'янка, смоляний клей…).
- Якщо ні — **вигадана назва** з поясненням складу, властивостей і найближчого відомого аналога.

### Заохочення («натхнення»)
| Подія | Натхнення |
|---|---|
| Нове знання | +2 |
| Навчити іншого (за кожне знання) | +4, учню +2 |
| Нагодувати голодного | +3 |
| Новий матеріал | +15 (+4, якщо поки марний) |
| Матеріал кращий за всі відомі | +20 |
| Новий винахід, що працює | до +40 |
| Покращення винаходу | +10 |
| «Майже вийшло» / невдача | +5 / +1 |
| Хтось користується твоїм винаходом | +0.3 щоразу |

Натхнення змінює поведінку: кожен поселенець пам'ятає, скільки натхнення в середньому приносить кожне заняття, і частіше обирає вигідніше (softmax над очікуваним заохоченням). LLM-мозок бачить свій рахунок і таблицю заохочень у промпті.

### Ідеї
Ідеї не дані наперед, а виникають із проблем: «жару замало» → піч і міхи, «риба близько» → сітка і пліт, «носити важко» → візок, «два метали щипають язик у солоній воді» → гальванічний елемент. Як саме втілити ідею, поселенці шукають самі.

## LLM (безкоштовні відкриті моделі)

1. Встанови [Ollama](https://ollama.com) і завантаж модель: `ollama pull qwen2.5:3b` (або `llama3.2:3b`, `gemma2:2b`; на потужнішому ПК — `qwen2.5:7b`).
2. Дозволь сторінці звертатися до Ollama:
   - macOS / Linux: `OLLAMA_ORIGINS="*" ollama serve`
   - Windows PowerShell: `$env:OLLAMA_ORIGINS="*"; ollama serve`
3. Відкрий гру, вкладка **Мозок** → увімкни «Під'єднати модель» → «Перевірити з'єднання».

Підходить і будь-який OpenAI-сумісний сервер: LM Studio (`http://localhost:1234/v1`), llama.cpp server, vLLM, а також хмарні сервіси з безкоштовним рівнем (потрібен ключ API).

Модель лише **пропонує** експеримент чи репліку. Рушій фізики перевіряє, чи це справді працює, і нараховує натхнення. Якщо відповідь некоректна або модель мовчить, рішення ухвалює мозок на правилах.

## Чесні обмеження
- Хімія й фізика спрощені: правдоподібні, послідовні, але не точна наукова симуляція.
- Набір «принципів» пристроїв (різати, плавати, тримати жар, добувати струм…) закладений. Конкретні конструкції, матеріали, пропорції й порядок відкриттів — ні.
